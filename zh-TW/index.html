    不用寫 Ansible、不用碰 libvirt，就能建出真正的 lab 環境¶

    rodeo-cli 是一套宣告式 CLI，把一個 YAML 檔變成 KVM 上可以實際操作的 lab：SUSE Virtualization（Harvester）、Rancher Prime、SUSE Edge、SUSE Telco Cloud，或單純的 KVM 主機。profile 就是 lab，要在哪裡執行則另外決定：SLES 16 主機、Instruqt builder、AWS、Google Cloud，或你已經有的 KVM 主機。

    為什麼要做這個工具¶

    為了 demo、workshop 或測試建一套 Harvester 叢集或 Rancher Prime，通常得寫 Ansible、手動接 libvirt 網路，而且每次都要重新摸一遍同樣的 iPXE 開機流程。rodeo-cli 用一個概念取代這一切：描述你要的 lab，交給 plan/apply 流程去建。

    一個 profile 就是一個設定目錄，裡面有兩個 YAML 檔。rodeo-plan.yaml 設定資源與帳密；definition.yaml 描述拓撲：節點、網路、對外服務、開機順序。CLI 讀取這兩個檔案，用 rodeo plan 顯示和主機現況的差異，再用 rodeo deploy 收斂到目標狀態。重複執行是安全的：deploy 預設會把 VM 記憶體與 vCPU 的漂移調回設定值（加 --no-reconcile 可關閉）；需要更大範圍重新套用時，用 --force 或 --from。

    主要功能¶

    宣告式

    先 plan，再套用¶

    rodeo plan 會在任何變更發生前，先比對你的 YAML 與主機現況。不會有意外，也不用猜重跑會動到什麼。

    開箱即用

    12 個內建 profile¶

    Harvester HCI（2 節點、3 節點、HA，可搭配或不搭配 Rancher）、SUSE Virtualization workshop、搭配 K3s 與 RKE2 的 Rancher Prime、SUSE Edge、SUSE Telco Cloud、SUSE Multi-Linux Manager，以及單純的 KVM 主機。

    自由調整

    自訂 rodeo¶

    rodeo new mylab --from harvester 會產生一份可編輯的 profile。修改拓撲後重跑，lab 就會收斂成新的樣子，不必 fork 這個工具。

    為實機打造

    一個指令就上手¶

    rodeo up 會檢查主機、挑一個記憶體放得下的 lab、產生帳密、自動以 sudo 提權，並在 tmux 裡執行，SSH 斷線也不會中斷正在進行的部署。

    安全無虞

    帳密不進 git¶

    帳密存放在 ~/.rodeo/secrets.yaml（權限 chmod 600），plan 裡用 ??key 占位符引用。任何敏感資料都不需要進到 repo。

    Day-2 維運

    不只部署，還能管理¶

    rodeo status、rodeo stop/start、rodeo set-password、rodeo install-extensions、rodeo clean：lab 是你可以持續維運的環境，不是跑一次就丟的腳本。

    在哪裡執行

    五種部署目標¶

    baremetal 與 instruqt 部署在你所在的機器上。aws 與 gcp 從筆電建立機器，再透過 SSH 建好 lab。remote 使用你已經有的 KVM 主機。雲端主機預設 6 小時後終止，除非你設定 provider.ttl_hours。fleet 文件提到 Vultr 與 Hetzner，但尚未實作。請見開始使用。

    Workshop

    每位學員一套 lab¶

    rodeo fleet 會在多台主機上平行建出同樣的 lab，每套 lab 都能個別查狀態、重試與診斷。 學員可以透過領取入口，用 workshop 代碼領到自己的 lab。請見 Fleet。

    $ curl -fsSL https://raw.githubusercontent.com/avaleror/rodeo-cli/main/install.sh | bash $ rodeo up → checking host resources... → picking a profile that fits (harvester-ha, ~52 GiB) → generating secrets... → deploying... ✓ Lab is up. URLs and credentials printed below.
